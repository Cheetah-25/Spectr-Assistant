# In-line spectroscopy first assessment

## Enquiry

Our existing NIR pilot follows API concentration in one powder formulation at the tablet press feed frame. We are introducing a different API and excipient blend and would like to reuse the calibration. A colleague suggests adding Raman so that the old calibration will remain valid. What should our first technical assessment and experiment be?

## Requirements and constraints

- material: a different API and excipient blend (new powder formulation); existing pilot covers one powder formulation
- target: API concentration
- location: at the tablet press feed frame
- conditions: existing NIR pilot follows API concentration in-line
- constraint: would like to reuse the existing calibration
- goal: first technical assessment and experiment; colleague suggests adding Raman so that the old calibration will remain valid

Missing:
- Identity and concentration range of the new API and the excipients
- Which independent laboratory reference method (e.g. HPLC assay) and how many reference samples are available for the new blend
- Current NIR pilot details: probe type, spectrometer range, fiber and how the old calibration was built and validated
- Whether the new API and excipients fluoresce under 785 nm excitation
- Required accuracy, measurement rate and go/no-go criteria set by the client

## Risks and problems with the request

- **Wrong assumption:** The existing calibration cannot be assumed valid for the new formulation: NIR calibrations are chemometric models built and validated for a specific matrix, so a different API and excipient blend is a new matrix and the old model must be re-tested and most likely replaced by a new calibration. [S01 p.5; S01 p.10]
- **Wrong assumption:** Adding Raman does not keep the old calibration valid: Raman adds complementary information and a combined NIR+Raman model is built on newly fused data, which is a new model needing its own calibration and validation, and whether fusion helps this formulation is a hypothesis. [S01 p.15; S01 p.14–15; S01 p.9; S01 p.7]
- **Check first:** Raman signals are weak and can be masked by fluorescence of many organic compounds, so check whether the new API or excipients fluoresce at 785 nm before relying on Raman. [S01 p.11; S01 p.15]
- **Check first:** For a fused model the NIR and Raman spectra must be time-synchronised because the methods have different acquisition rates, and in a heterogeneous powder both should ideally see the same spot. [S01 p.8; S01 p.15]

## Methods worth testing

- **NIR diffuse reflection** (Main): NIR diffuse reflection suits powders, is the most common online fiber-probe method and is already installed in the feed frame, but needs a new chemometric model for the new matrix. [S01 Table 1 (p.6); S01 p.10; S01 p.5]
- **NIR + Raman (fused)** (Compare): NIR sees hydrogen bonds and polar groups while Raman sees the molecular backbone and non-polar groups, and a feed-frame study reported fused PLS models predicted API potency more accurately than single-method models. [S01 p.14–15; S01 p.15]
- **Raman (785 nm excitation)** (Compare): A Raman contact probe with 785 nm excitation is used in the feed frame for blend potency and has high selectivity for powders, but it is weak and can be masked by fluorescence. [S01 p.15; S01 Table 1 (p.6); S01 p.11]
- **MIR ATR** (Not suitable): Strong mid-IR absorption limits MIR to very thin layers and ATR suits liquids, pastes and soft solids, not a flowing powder in a feed frame. [S01 p.5; S01 Table 1 (p.6)]

## Multispectral option

**NIR + Raman**: NIR detects hydrogen bonds and asymmetric polar groups while Raman provides the molecular backbone and symmetrical non-polar groups, and NIR+Raman fusion was reported to improve API potency prediction in the feed frame.. Probe: combined probe (same spot). Fusion: low-level fusion of synchronised spectra. Prove the gain: Build the fused PLS model and the best single-method model on the same calibration data and accept fusion only if it beats the single model on the same independent validation set; a combined NIRaman probe that fits the feed frame avoids spot mismatch, otherwise separate probes must at least be time-synchronised. [S01 p.15; S01 p.14–15; S01 p.8; S01 p.9; S01 p.7]

## Clarification questions

1. What are the new API and excipients, and what API concentration range must be covered? (The model must be built for the new matrix and its concentration range.) [S01 p.5; S01 p.3]
2. Which independent laboratory reference method and how many reference samples can you provide for the new blend? (A new calibration and its validation require reference values from independent analyses.) [S01 p.5]
3. Which NIR probe, spectrometer range and fiber does the current pilot use, and how was the old calibration built and validated? (This determines whether the existing hardware can be reused and how to re-test the old model.) [S01 Table 1 (p.6); S02 p.6]
4. Do the new API or excipients show fluorescence, or have you seen Raman spectra of them? (Fluorescence can mask Raman signals and decide whether Raman is usable.) [S01 p.11]
5. What accuracy and measurement rate does the process need to accept a model? (Go/no-go criteria for single and fused models must come from you.) [S01 p.15]

## First feasibility experiment

Determine whether a new NIR calibration or a fused NIR+Raman model best predicts API concentration of the new blend in the feed frame. [S01 p.14–15; S01 p.8; S01 p.9; S01 p.11; S01 p.5; S02 p.20]

1. Apply the old NIR calibration to spectra of the new blend and compare predictions with independent laboratory reference values to document whether it fails.
2. Prepare new-blend samples across the target API range and record NIR diffuse reflection and 785 nm Raman spectra in the feed frame, time-synchronised.
3. Check the Raman spectra for fluorescence background and identify key spectral features of the new API in both methods.
4. Build a new NIR PLS model, a Raman PLS model and a low-level fused NIR+Raman PLS model on the same calibration set.
5. Compare all models on the same independent validation set against the laboratory reference values and the client's criteria.

References: Independent laboratory assay of API concentration (method to be named by the client) on samples taken at the feed frame
Go / no-go: criteria come from the client
