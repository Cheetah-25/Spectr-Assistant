## Enquiry

Our existing NIR pilot follows API concentration in one powder formulation at the tablet press feed frame. We are introducing a different API and excipient blend and would like to reuse the calibration. A colleague suggests adding Raman so that the old calibration will remain valid. What should our first technical assessment and experiment be?

## Requirements and constraints

- material: one powder formulation; now a different API and excipient blend is being introduced
- target: API concentration
- location: at the tablet press feed frame
- conditions: existing NIR pilot follows API concentration in-line
- constraint: would like to reuse the calibration
- goal: a first technical assessment and experiment; a colleague suggests adding Raman so that the old calibration will remain valid

Missing:
- API concentration range and target accuracy for the new formulation
- independent laboratory reference method for API content
- identity of the new API and excipients (fluorescence risk for Raman)
- existing NIR probe, spectrometer range, fiber type and length
- feed-frame conditions: powder speed, sampling rate, cleaning, hazardous area
- acceptance (go/no-go) criteria for the new model

## Recommended in-line method

**Test NIR + Raman in the tablet press feed frame with a new calibration for the new blend, against NIR alone.** [S01 p.14–15; S01 p.15; S02 p.6; S02 p.7; S01 p.11; S01 p.7; S01 Table 1 (p.6)]

## Risks and problems with the request

- **Wrong assumption:** The existing calibration cannot be assumed valid for the new formulation: NIR calibrations are chemometric models built and validated for a specific matrix, and a different API and excipient blend is a new matrix, so the old model must be re-tested and most likely replaced by a new calibration. [S01 p.5; S01 p.10]
- **Wrong assumption:** Adding Raman does not keep the old calibration valid: Raman adds complementary information and a combined NIR+Raman model is built on newly fused data, so it is a new model that needs its own calibration and validation on the new formulation, and whether fusion helps this blend is a hypothesis. [S01 p.14–15; S01 p.15; S01 p.9; S01 p.7]
- **Check first:** Raman signals are weak and can be masked by much stronger fluorescence of many organic compounds, so check the new API and excipients for fluorescence at 785 nm before committing to Raman. [S01 p.11; S01 p.15]
- **Check first:** NIR spans 780–2500 nm while Vis-NIR silica fiber transmits 350–2400 nm, so confirm that the existing fiber and spectrometer cover the spectral region used by the new model. [S01 p.10; S02 p.6]

## Methods worth testing

- **NIR diffuse reflection** (Main): It is the existing pilot method, suits powders with 0.5–1 mm depth and remote fiber probes, but needs a new chemometric calibration for the new blend. [S01 Table 1 (p.6); S01 p.5; S01 p.10]
- **NIR + Raman (fused)** (Compare): The same quantity in the same location was measured with fused NIR+Raman PLS, which outperformed single methods in that study, so it is worth testing against NIR alone. [S01 p.14–15; S01 p.15]
- **Raman (785 nm excitation)** (Compare): Raman sees the molecular backbone and non-polar groups in powders with 2–5 mm depth and high selectivity, but may be masked by fluorescence. [S01 p.15; S01 Table 1 (p.6); S01 p.11]
- **MIR ATR** (Not suitable): Strong mid-IR absorption limits ATR to very thin layers and it is rated for liquids, pastes and soft solids, not flowing powder in a feed frame. [S01 p.5; S01 Table 1 (p.6)]

## Multispectral option

**NIR + Raman**: NIR detects hydrogen bonds and asymmetric polar groups while Raman sees the molecular backbone and symmetrical non-polar groups, and this pair was used for blend potency in a feed frame.. Probe: combined probe (same spot), e.g. a NIRaman probe that fits the feed frame; otherwise separate synchronised probes. Fusion: low-level fusion of synchronised spectra with dedicated fusion handling, then PLS. Prove the gain: Build NIR-only, Raman-only and fused models on the same new-blend samples and accept the combination only if it beats the best single method on the same independent validation data. [S01 p.15; S01 p.14–15; S01 p.8; S01 p.9]

## Clarification questions

1. What API concentration range must the new formulation cover, and what accuracy do you need? (The new calibration design and the go/no-go criteria depend on the range and target performance.) [S01 p.5]
2. Which independent laboratory method will provide reference API values for samples taken at the feed frame? (A new chemometric model must be built and validated against independent reference data.) [S01 p.5]
3. What are the new API and excipients, and are any of them known to fluoresce? (Fluorescence can mask the weak Raman signal and decide whether Raman is usable.) [S01 p.11]
4. Which NIR probe, spectrometer range, fiber type and fiber length does the existing pilot use? (The fiber must transmit the NIR range used by the model and Raman needs silica fiber without jacket fluorescence.) [S02 p.6; S02 p.7]
5. Is there room in the feed frame for a second probe or a combined NIR+Raman probe? (Heterogeneous powder needs both methods to see the same spot or at least synchronised data, and a combined probe fitting a feed frame exists.) [S01 p.8; S01 p.15]

## First feasibility experiment

Determine whether a new NIR calibration, Raman, or a fused NIR+Raman model best predicts API concentration of the new blend in the feed frame. [S01 p.5; S01 p.11; S01 p.14–15; S01 p.8; S01 p.9; S02 p.20]

1. Apply the existing NIR model to the new blend and compare its predictions with independent laboratory reference values to document whether it fails.
2. Prepare new-blend samples spanning the client's API range and check the new API and excipients for fluorescence under 785 nm Raman excitation.
3. Record time-synchronised NIR diffuse reflection and 785 nm Raman spectra in the feed frame, ideally with a combined probe sampling the same spot, and take matching samples for the reference assay.
4. Build NIR-only, Raman-only and low-level fused NIR+Raman PLS models and compare them on the same independent validation set.

References: Independent laboratory API assay of feed-frame samples (method to be specified by the client)
Go / no-go: Acceptance criteria (accuracy, range, response time) to be set by the client; the fused model is adopted only if it beats the best single method on the same validation data.

## Sources cited

- **S01 p.5** (S01_Multispectral_Laboratory.pdf): Mid-IR spectra contain well-defined absorption peaks, while NIR, UV and fluorescence give broad overlapping spectra; quantitative use requires chemometric calibration or classification models that are built, validated and then applied.
- **S01 p.10** (S01_Multispectral_Laboratory.pdf): NIR (780–2500 nm) is the most common online fiber-probe method; its broad overlapping overtone/combination bands require chemometrics; diffuse reflectance allows measurements on scattering samples.
- **S01 p.9** (S01_Multispectral_Laboratory.pdf): Fused data blocks differ in noise and information content; normalisation alone does not fix this, so dedicated data-fusion algorithms are needed.
- **S01 p.14–15** (S01_Multispectral_Laboratory.pdf): Pharmaceutical example: NIR reflection probe and Raman probe (785 nm excitation) inserted into the feed frame of a rotary tablet press for blend potency; NIR sees hydrogen bonds/polar groups, Raman the molecular backbone/non-polar groups; low-level fusion of synchronised spectra with PLS.
- **S01 p.15** (S01_Multispectral_Laboratory.pdf): The cited feed-frame study reports that fused NIR+Raman PLS models predicted API potency more accurately than single-method models (in that study).
- **S01 p.15** (S01_Multispectral_Laboratory.pdf): By combining Raman and NIR, these models can predict API potency or coating thickness with higher accuracy and robustness than single -method models. Fig. 6. A multispectral NIRaman fiber probe has industrial grade design that combines NIR reflection and Raman optical techniques in a compact shaft that fits in a tablet press feed frame. References: - De Man, A, et al. (2024). Evaluating the improvement of blend potency measurements in the feed frame of a rotary tablet press using combined NIR and Raman spectroscopy. Analytical Chemistry, 96(26), 10586-10593.
- **S01 p.7** (S01_Multispectral_Laboratory.pdf): Complex media (oil, milk, fermentation media, tissue) may need two or more methods; examples: NIR+fluorescence gave more accurate biomass in yeast fermentation and distinguished intra- and extracellular metabolites; NIR+IR showed benefits for tumour boundaries; fluorescence+IR was needed to classify tissues; NIR+Raman gave the best results for pellet coating.
- **S01 p.15** (S01_Multispectral_Laboratory.pdf): 15 and widely implemented spectral techniques are Near -Infrared (NIR) and Raman spectroscopy. The combination of these techniques is particularly effective because it captures complementary chemical information: NIR detects hydrogen bonds and asymmetric polar groups, while Raman provides information on the molecular backbone and symmetrical non-polar groups. The equipment used for such task involves next spectral systems: - NIR spectrometer and light source coupled with a NIR reflection probe - Raman spectrometer and Raman fiber probe for contact measurements with 785 nm excitation wavelength During the experimental action, the probes are inserted directly into the process environment, such as the feed frame of a rotary tablet press.
- **S02 p.6** (S02_AFS_Process_Control_Slides.pdf): Fiber transmission ranges: UV-Vis silica 190–1200 nm; Vis-NIR silica 350–2400 nm; chalcogenide As-S (CIR) 1.1–6.5 µm; polycrystalline (PIR) 3–17 µm; hollow glass waveguides 2–18 µm; InF₃ 0.3–5.5 µm; ZrF₄ 0.3–4.5 µm (figure values).
- **S02 p.7** (S02_AFS_Process_Control_Slides.pdf): Robust 100–300 m cables of low-OH silica fibers enable remote industrial process control (Vis-NIR). Al/Cu-coated silica fibers offer high-temperature resistance and no polymer-jacket fluorescence for Raman and fluorescence.
- **S01 p.11** (S01_Multispectral_Laboratory.pdf): Raman signals are weak and often masked by laser scatter and, for many organic compounds, by much stronger fluorescence; special filters and probe designs are needed. The Raman shift (cm⁻¹) is the spectral axis.
- **S01 Table 1 (p.6)** (S01_Multispectral_Laboratory.pdf): Table 1 rates methods qualitatively: MIR ATR (liquid/paste/soft, depth 1–6 µm, sensitivity average, selectivity high, cost high); NIR transmission/transflection probe (liquid/colloidal, 1–10 mm); NIR diffuse reflection probe (scattering media/powder, 0.5–1 mm); Raman probe (liquid/powder/solid, 2–5 mm, selectivity high, cost high); UV/Vis probes (selectivity low); fluorimetric probe (liquid/solid, 1–5 mm, sensitivity high, selectivity low, cost low).
- **S01 p.15** (S01_Multispectral_Laboratory.pdf): Fiber optics let spectrometers sit away from the vibration and dust of the manufacturing floor.
- **S01 p.8** (S01_Multispectral_Laboratory.pdf): For heterogeneous samples the different methods must see the same small area; alternating two probes makes this hard, multispectral probes solve it. Data from methods with different acquisition rates must be synchronised.
- **S02 p.20** (S02_AFS_Process_Control_Slides.pdf): AFS pathway: multi-method lab trials on the customer process, then identification of key spectral features, then a chemometric model, a customised system or IoT sensors.
- **S05 p.1** (S05_AFS_Flyer.pdf): AFS guided pathway: (1) multi-method lab test with the AFS multi-spectral fiber system, (2) selection of key spectral features by multivariate analysis and fusion, (3) tailored solution: Path A AI-driven chemometric model (spectra to real-time composition), Path B customised MSF system (tailored spectrometer set for the customer's own R&D), Path C customised spectral fiber sensors (SFS) for a specific process with remote/cloud control.
- **S01 p.3** (S01_Multispectral_Laboratory.pdf): For samples of incompletely known composition it is not always possible to predict which method will work; testing several optical approaches is the way to select the most suitable method or combination.
- **S01 p.5** (S01_Multispectral_Laboratory.pdf): NIR penetrates up to several millimetres even into dense solids (low absorption, strong scattering), works with ordinary glass optics and standard lamps, which makes it suited to online use with remote fiber probes.
- **S01 p.5** (S01_Multispectral_Laboratory.pdf): Strong mid-IR absorption limits MIR to very thin layers (usually <50 µm), which is why MIR is used with ATR attachments and probes.
